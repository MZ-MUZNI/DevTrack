# DevTrack

A lightweight Agile sprint & task tracker with AI-assisted features, built with C# and HTML.

## 🎯 Overview

DevTrack is a modern project management tool designed to help development teams efficiently manage sprints, track tasks, and collaborate on projects. With integrated AI assistance, DevTrack streamlines workflow management and enhances team productivity.

## ✨ Key Features

- **Sprint Management** - Create, plan, and manage Agile sprints with ease
- **Task Tracking** - Organize and track tasks throughout the development lifecycle
- **AI Assistance** - Intelligent features to help with task descriptions, estimations, and recommendations
- **Lightweight & Fast** - Minimal overhead with optimal performance
- **Collaborative** - Built for team collaboration and transparency
- **Intuitive Interface** - User-friendly design for seamless navigation

## 🛠️ Tech Stack

- **Backend**: C# (73.4%)
- **Frontend**: HTML (25.9%)
- **Build & Infrastructure**: Various supporting technologies

## 📋 Prerequisites

- .NET Framework or .NET Core (depending on C# version)
- A modern web browser for accessing the interface
- Git for version control

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/MZ-MUZNI/DevTrack.git
cd DevTrack
```

2. Install dependencies:
```bash
# Navigate to the project directory and restore NuGet packages
dotnet restore
```

3. Build the project:
```bash
dotnet build
```

4. Run the application:
```bash
dotnet run
```

The application will be available at `http://localhost:5000` (or as configured in your setup).

## 📖 Usage

### Creating a Sprint
1. Navigate to the Sprints section
2. Click "New Sprint" and configure sprint parameters
3. Set sprint duration and goals
4. Add tasks to the sprint

### Managing Tasks
1. Create tasks with descriptions and estimates
2. Assign tasks to team members
3. Track progress and update status
4. Use AI assistance for task recommendations and insights

### AI Features
- Get smart task descriptions
- Receive effort estimation suggestions
- Analyze sprint performance with AI insights
